# ToDo List extension

把执行计划持久化到项目根目录的 `TODO.md`，不依赖会话记忆，也不会写入项目的 `.pi`。

## 工具

- `todo_create`：创建清单；可同时创建一级子任务。已有 `TODO.md` 时默认拒绝覆盖。
- `todo_update`：按 `todo_view` 给出的编号新增、打勾、恢复、改名或删除任务；执行中发现特殊任务时用 `add` 补记。
- `todo_view`：展示任务、子任务和完成统计；任务结束或退出前调用。

每轮 agent 结束时，扩展还会在 UI 显示一次退出前检查结果。如果仍有待办，扩展会用 `steer` 强制下一轮继续执行，而不是在流程阶段完成后退出。文档采用标准 Markdown checkbox，用户或其他读写工具也可直接修改；下一次工具调用会重新读取磁盘内容。
