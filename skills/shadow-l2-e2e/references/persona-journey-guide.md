## 1. 用户画像发散方法

### 画像格式

```markdown
## 用户画像

### 画像 P-01：<角色名>-<变体标签>

| 字段 | 内容 |
|------|------|
| 角色基类 | 来自 research.md 的哪个官方角色 |
| 变体标签 | 新手/熟练/专家/极端/误用/意外 |
| 核心目标 | 该画像登录系统最想完成的 1-3 件事 |
| 典型工作日 | 该画像每天在系统中的高频操作和高峰时段 |
| 浏览器操作路径 | 从打开浏览器到完成核心目标的完整点击/导航/操作路径 |
| 操作特征 | 该画像独有的操作习惯（批量操作/浏览器后退/Ctrl+S） |
| 技能水平 | 专家/熟练/新手 → 引导提示和防呆设计需求 |
| 使用频率 | 高频(每天)/中频(每周)/低频(每月)/首次 → 会话恢复和操作记忆需求 |
| 常见痛点 | 该画像最容易遇到的操作困难和困惑 |
| 生产数据特征 | 该画像日常处理的数据量级、数据状态多样性 |
| 预期操作路径数 | 该画像可能走的操作路径数量估算 |

### 画像发散清单

| 画像ID | 角色基类 | 变体标签 | 核心区分度 | 预期路径数 |
|--------|---------|---------|-----------|-----------|
| P-01 | {角色1} | 熟练用户 | 熟练路径，不看引导 | ~8 |
| P-02 | {角色1} | 新手用户 | 需要引导，容易点错 | ~12 |
| P-03 | {角色1} | 极端批量 | 大规模批量操作 | ~5 |
| P-04 | {角色2} | 官方角色 | 基准操作路径 | ~6 |
| P-05 | 任意 | 误用者 | 越权/非法数据/疯狂点击 | ~10 |
| P-06 | 任意 | 意外场景 | 手机误触/慢网络/忘记退出 | ~6 |
```

### 6 维度穷举

| 发散维度 | 问题 | 产出 |
|---------|------|------|
| **官方角色** | spec.md 定义了哪些角色？ | 基准画像 |
| **技能梯度** | 新手/熟练/专家操作差异？ | 每角色 1-3 个变体 |
| **使用频率** | 高频/中频/低频/首次路径差异？ | 每角色 1-4 个变体 |
| **极端用户** | 批量操作？频繁撤销？多标签页？ | 至少 2 个极端画像 |
| **误用/滥用者** | 越权？疯狂点击？注入攻击？ | 至少 1 个安全画像 |
| **意外场景用户** | 手机误触？慢网络？忘记退出？ | 至少 1 个意外画像 |

数量要求：最少 5 个，每个必须有明确区分度。

## 2. 用户旅程穷举方法

对每个画像，按 5 层次穷举操作路径：

| 层次 | 目标 | 至少 |
|------|------|------|
| **主线旅程** | 完成核心目标的最佳路径 | 1 条 |
| **分支旅程** | 每个决策点的每个分支 | 每决策点 × 分支数 |
| **迂回旅程** | 绕路/回退/重试/走弯路 | 2 条 |
| **意外旅程** | 断网/崩溃/超时/会话过期/误操作恢复 | 1 条 |
| **探索旅程** | 无目的浏览/首次使用/越权尝试 | 1 条 |

### 旅程图格式

```markdown
## 用户旅程图：P-XX → <旅程目标> [J-XX]

| 属性 | 值 |
|------|-----|
| 画像 | P-XX: <名称> |
| 旅程类型 | 主线/分支/迂回/意外/探索 |
| 触发条件 | <什么情况下会走这条路径> |
| 涉及页面 | <wire.svg data-page 列表> |
| 涉及规则 | <RXX 列表> |
| 涉及节点 | <BXX-NYY 列表> |

| 步骤 | 浏览器操作 | 页面URL/组件 | 用户可见反馈 | 可能分支 |
|------|-----------|-------------|-------------|---------|
| 1 | 打开浏览器，访问登录页 | /login | 登录表单 | — |
| 2 | 输入账号密码，点击"登录" | /login | loading → 跳转首页 | 失败：红色错误提示 |
```

旅程图要求：
- 浏览器操作列必须写具体前端交互
- 页面URL/组件列对应 wire.svg 的 data-page 和 data-route
- 用户可见反馈列写浏览器中能看到的
- 不省略导航步骤

## 3. 旅程穷举检查清单

对每个画像逐项检查：

```markdown
## 用户旅程穷举检查清单：画像 P-XX

### 主线旅程
- [ ] 从登录到完成核心目标的最短路径

### 决策分支旅程
- [ ] 每个条件判断为 True/False 的路径
- [ ] 每个下拉选项/筛选条件/排序方式的路径
- [ ] 每种数据类型的操作路径
- [ ] 每种状态下的操作路径

### 迂回旅程
- [ ] 操作到一半点浏览器后退，然后重新前进
- [ ] 操作到一半切换到其他页面，再回来继续
- [ ] 输入错误后修正，重新提交
- [ ] 部分完成后保存草稿，稍后回来继续
- [ ] 搜索/筛选后没找到目标，更换条件重新搜索
- [ ] 同一操作反复做（重复创建/提交/删除）
- [ ] 中途改变主意——填了一半放弃

### 意外旅程
- [ ] 操作中途断网，恢复后重试
- [ ] 浏览器崩溃，重新打开恢复
- [ ] 会话过期后重新登录续作
- [ ] 双击/快速连续点击提交按钮
- [ ] 慢网络下操作
- [ ] 多标签页同时操作同一数据
- [ ] 公共电脑忘记退出

### 探索旅程
- [ ] 无目的浏览——随便看看
- [ ] 第一次使用，不知道怎么操作
- [ ] 尝试输入非法/特殊数据（SQL注入/XSS/超长/emoji/负数）
- [ ] 尝试直接访问未授权 URL
- [ ] 尝试篡改 URL 参数

### 旅程总计：__ 条
```

## 5. 与 L1 对比校验方法

### 画像对比

| 对比维度 | 检查方法 | 发现遗漏时 |
|---------|---------|-----------|
| L2 有但 L1 没有的画像 | L2 清单 - L1 清单 | 进入 L1 回溯清单 |
| L2 有但 L1 没有的变体标签 | 按角色基类对比 | 进入 L1 回溯清单 |
| L1 有但 L2 没考虑到 | 反向检查 L1 画像覆盖 | L2 补充该画像 |
| 区分度不足 | L1 和 L2 画像是否有明确区分 | 合并或拆分 |

### 旅程对比

| 对比维度 | 检查方法 | 发现遗漏时 |
|---------|---------|-----------|
| L2 有但 L1 没有的旅程 | L2 旅程 - L1 旅程 | 进入 L1 回溯清单 |
| L2 测试特有路径 | 规则边界/组合/极端/并发 L1 没考虑的 | 标注 J-T-XX |
| L1 有但 L2 没覆盖 | 反向检查 | L2 补充 |
| 交叉矩阵缺口 | 规则/页面/交互点未覆盖 | 继续补充旅程 |

### 旅程编号

- `J-L1-XX`：来自 L1 Research（L2 认可直接使用）
- `J-T-XX`：L2 测试视角新增（L1 没覆盖到）
