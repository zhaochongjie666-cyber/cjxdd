## 修的 2 个 hook bug

### Bug 1: 计数器 `((total_checks++))` 在 `set -e` 下静默 exit 1

```bash
# 修前
((total_checks++))  # 返回 0 (post-increment 返回原值), set -e 视为失败

# 修后
total_checks=$((total_checks+1))  # 显式赋值, 不会触发 set -e
```

**影响**: hook 在第 1 个门禁检查就静默退出, 后续 11 个不跑. 实战报告"过 12 门禁"是 hook 退出 0 (因早期 exit) 而非真过 12 项.

### Bug 2: 路径只扫 `.xdd/wire/`, 漏 `.xdd/design/*.svg`

```bash
# 修前
wire_dir="$xdd_dir/wire"
if [[ ! -d "$wire_dir" ]]; then
    echo "(无 .xdd/wire/, 纯后端项目跳过)"  # 实战产物放 design/, 误判跳过
    exit 0
fi

# 修后
wire_dir="$xdd_dir/wire"
design_dir="$xdd_dir/design"
if [[ ! -d "$wire_dir" && ! -d "$design_dir" ]]; then
    echo "(无 wire/ 和 design/, 纯后端跳过)"
    exit 0
fi
# 收齐 2 个目录所有 SVG
```

**影响**: 实战产物放 `.xdd/design/wire.svg` (新约定), hook 只扫 `.xdd/wire/`, 误判"无 SVG" 早期 exit 0.
