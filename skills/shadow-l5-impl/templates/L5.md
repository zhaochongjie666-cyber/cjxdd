# L5 代码文件头索引模板

## Python

```python
"""
File: backend/app/services/xxx_service.py
L1: <business-slug>  (.shadow/L1-business/BXX-<business-slug>/spec.md)
L5-Plan: .shadow/L5-plan/<business-slug>/harness-plan.md
@implements: <slug>-R01, <slug>-R02, <slug>-R03 (B01-N03)
"""
```

## TypeScript

```ts
/**
 * File: frontend/src/api/xxx.ts
 * L1: <business-slug>  (.shadow/L1-business/BXX-<business-slug>/spec.md)
 * L5-Plan: .shadow/L5-plan/<business-slug>/harness-plan.md
 * @implements: <slug>-R01, <slug>-R02
 */
```

## Vue

```vue
<script setup lang="ts">
/**
 * File: frontend/src/components/xxx/XxxDialog.vue
 * L1: <business-slug>  (.shadow/L1-business/BXX-<business-slug>/spec.md)
 * L5-Plan: .shadow/L5-plan/<business-slug>/harness-plan.md
 * @implements: <slug>-R01, <slug>-R04
 */
```

**格式要点：**
- `File:` 真实代码路径
- `L1:` spec.md 路径
- `L5-Plan:` Harness 计划路径
- `@implements:` 本文件实现的所有 L1 规则 ID，逗号分隔
- 四个路径必须指向真实存在的文件

## 合格检查

- 文件头包含 L1 + L5-Plan 两层索引 + @implements 规则 ID 列表
- L1、L5-Plan 引用的文件真实存在
- @implements 列表与 Harness 计划中标注的规则一致
- 没有文件头索引的代码文件是野生文件，应被删除
