## 操作步骤（浏览器操作，对应 Playwright）
1. 打开浏览器，访问登录页 URL，确认登录表单可见。→ `open` + `waitForSelector`
2. 输入账号密码，点击"登录"按钮，等待页面跳转。→ `fill` + `click` + `waitForURL`
3. 在导航栏点击"<菜单名>"，等待目标页面加载完成。→ `click` + `waitForLoadState`
4. 确认目标页面内容加载（loading 消失，内容可见 或 空状态提示可见）。→ `waitForSelector`
5. 执行核心浏览器操作：在 <输入框> 输入文本 / 点击 <按钮> / 选择 <下拉选项> / 上传 <文件>。→ `fill`/`click`/`select`/`upload`
6. 等待操作反馈（loading 消失 + 成功 toast 或 错误提示出现）。→ `waitForSelector`
7. 在页面中确认操作结果（列表更新/状态标签变化/新内容出现）。→ `assertText`/`assertVisible`
8. [可选] 模拟浏览器误操作：双击提交按钮 → 确认无重复数据；点击浏览器后退 → 确认页面恢复。
9. [可选] 模拟浏览器会话中断：关闭标签页 → 重新打开 → 确认断点恢复。
10. 点击退出登录。→ `click`
