## 跨业务线主题

- **共享节点定义**:两条业务线用同一套 `nodes.py`(节点名/skill/产出路径/模型)+ `gate.py`(验收闸)。B02 是 B01 的可视化 driver,不是平行实现。
- **共享 iter 模型**:都从 `.xdd/current-iteration` 读 iter 号,验收循环都走 `init --iter N+1`。
- **G 编号全局**:goals.md 的 G1~G8 是项目级,两业务线的 RXX 共同支撑同一套 G。
- **跨上下文关系**:B02 的 Web 引擎**复用** B01 的节点定义和 gate(客户-供应商:B02 依赖 B01 的核心抽象)。
- **无多租户隔离**:单机本地工具,不按 tenant 隔离(与典型业务系统不同)。

## 适配说明

workflow 是**工具**(Python 编排器 + Web),不是业务系统。spec 的"业务规则"适配为"**工具行为规则**":
- "用户"= 触发 workflow 的人(CLI 跑命令 / Web 点开始)。
- "业务意图"= 跑完一组 xdd 节点。
- "验收"= 节点产出落对位置 + 自检清单通过(gate)。
- 不涉及:登录/权限/多租户/支付等典型业务域。
